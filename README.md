 Daily Bike Rental Demand Forecasting

This repository contains a machine learning workflow developed in Python using **Spyder IDE** to predict daily bike rental volumes using meteorological, calendar, and historical demand data.


 How to Run in Spyder
1. Clone this repository to your local machine.
2. Open **Spyder IDE**.
3. Set your Working Directory to the project folder (`Working Directory` toolbar in the top-right corner).
4. Open `CPS_385 Assignment 1.py` and run the script (`F5`). Output metrics and tables will render directly in the IPython Console.\
